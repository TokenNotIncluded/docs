Tokenz supports over 50 payment methods globally, with especially deep coverage across APAC markets including Japan, Korea, Southeast Asia, and Greater China. By default, all methods available for the customer's detected region appear automatically on the Tokenz-hosted checkout page. To restrict which methods are offered, pass the `paymentMethodKinds` array when creating a Checkout Session.

```json payment-method-filter.json
{
  "paymentMethodKinds": ["CARD", "PAYPAY", "KONBINI"]
}
```

Browse the full list of supported methods by region below. Each entry shows the method name, its type, covered markets, and the API value to use in `paymentMethodKinds`.
