## 分组索引

<AccordionGroup>
  <Accordion title="开始使用">
    先完成接入,再查端点。

    - [总览](/introduction):站点结构和推荐阅读路径。

  </Accordion>
  <Accordion title="API 端点">
    端点页面由 `docs/openapi/relay.json` 和 `docs/openapi/api.json` 自动生成,每个页面都带可交互的请求构造器。

    - 中继 API（模型与媒体）:模型列表、Chat、Responses、Messages、Gemini、图像、视频、音频、嵌入、重排序和审核。
    - 管理 API（面板与运维）:系统、登录注册、OAuth、用户、充值、两步验证、渠道、令牌、兑换码、日志、统计、分组、任务、供应商、模型和系统设置。

  </Accordion>
