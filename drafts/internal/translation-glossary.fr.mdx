本词汇表定义项目文档与界面中推荐使用的法语译法。

## 核心概念

- 只有当源文本本身包含表情符号时才保留表情符号。
- 原文使用英文的技术术语可以保留英文。
- 在法语技术环境中广泛使用的英文术语(例如 API)可以保留英文。

| 英文术语 | 法语术语 | 规范英文 | 说明 |
|--------------|-------------|-------------------|-------------|
| Ratio | Ratio | Ratio/Multiplier | 价格计算使用的倍率。**重要:**定价语境中始终使用 **Ratio**,不要使用 **Multiplicateur**。 |
| Token | Jeton | Token | API 访问凭据,或模型处理的文本单位。 |
| Channel | Canal | Channel | 通往 API 供应方的访问路径。 |
| Group | Groupe | Group | 用于区分用户或令牌的分类。 |
| Quota | Quota | Quota | 用户可用的服务额度。 |

## 翻译指引

### 按语境区分 Prompt 与 Input

- **Invite / Prompt**:用户交互与 LLM 提示词语境。
- **Entrée / Input**:计费、技术文档与数据处理描述。
- **规则**:界面与交互文案用 *Invite/Prompt*,后端或计算语境用 *Entrée/Input*。

### Token 的语境含义

- 用于访问控制的 API 令牌(API Token)
- 模型处理的文本 token(Text Token)
- 认证流程使用的系统访问令牌(Access Token)

### 额度说明

- 用户可用的服务额度。
- 视语境有时也译作 **Crédit**。

### 法语语言注意事项

- 保持复数形式符合本地化框架要求(`_one`、`_other`)。
- 注意法语术语的性数与语法。
- 例如:`modèle` 为阳性,`canal` 为阳性。

### 统一术语

- **Complétion**:模型输出。
- **Ratio**:定价使用的倍率。
- **Code de redemption / code d'échange**:优先使用 **Code d'échange**。
- **Fournisseur**:对外提供 API 或模型的组织或服务。
