在**设置 → 模型定价**中,使用模型价格旁的按钮锁定或解锁已保存的定价。模型默认未锁定,锁定变更会立即保存;提交新价格之前请先解锁。

Go 生产供应方保护模型单次调用价格、输入输出倍率、缓存读写倍率、图像与音频倍率,以及阶梯计费模式与表达式。单条保存、批量更新、上游导入、恢复默认倍率和助手修改都走同一套写入保护。删除已锁定的价格或引入另一种计费模式同样会被忽略。

已锁定的条目保留其保存值,同一次更新中的其他模型正常保存。响应仍返回成功,并通过 `warnings` 和 `locked_models` 说明被忽略的改动。未发生变化的锁定条目不会产生告警。客户端应重新加载实际保存的配置项,不要把被忽略的草稿当作已生效。请求结构非法或数据库失败时仍按正常错误处理。

## API 与部署

`ModelPriceLock` 是一个持久化的 JSON 编码“模型到布尔值”配置项,默认为 `{}`。缺失或为 false 的条目表示未锁定,继续沿用仅 root 可读的配置项权限。`GET /api/option/` 会声明 `capabilities.model_price_locks: true`,客户端在切换锁定状态前先检查该能力,避免旧供应方静默接受不支持的请求。

通过 `PUT /api/option/` 做单模型的原子更新:

```json
{"key":"ModelPriceLock","model":"gpt-4o","value":true}
```

使用 `false` 解锁。即使其他管理员修改过别的模型锁定,这种写法也会保留它们。整体映射更新仍然支持,例如 `{"key":"ModelPriceLock","value":"{\"gpt-4o\":true}"}`;替换之前要先读取并合并当前映射。同一次请求里既解锁又改价时,原先锁定的价格仍会被保留。

锁定针对表中的精确配置键。要保护共享的通配符定价,请直接锁定通配符条目本身。既有的固定用户分组倍率与信任折扣继续生效。本次变更针对 Go 生产供应方,Rust 仍是独立的预览实现。启用新的 Web 控件之前请先升级 Go。已有安装不需要数据迁移。
