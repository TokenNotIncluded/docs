title: "保存 OAuth 设置"
sidebarTitle: "OAuth 设置"
description: "保存 OAuth 与 OIDC 设置时的校验与持久化行为。"
---

保存其他登录提供方,或保存未改动的表单时,不会去获取未发生变化的 OIDC discovery 文档。禁用 OIDC 同样会跳过 discovery,即使其保存的 URL 无效或提供方不可用。

启用带非空 discovery URL 的 OIDC,或在未同时禁用 OIDC 的情况下修改该 URL 时,会先校验绝对 HTTP(S) URL 并获取该文档,然后才执行任何设置更新。discovery 成功后会持久化去除首尾空白的 URL。空 URL 保留既有的手动端点配置模式。discovery 失败会选中 OIDC 标签页,并在 URL 字段显示既有的本地化错误,不会提交部分配置。既有的顺序配置项更新 API 中其他失败仍然不是事务性的,本次变更没有改变这一点。

保存与重置操作在整个表单提交期间保持禁用,包括 discovery 和所有配置项更新。提供方凭据、Telegram 字段、回调 URL 和注册限制均未改动。

`apps/web/src/features/system-settings/auth/oidc-discovery.test.ts` 使用本地固定数据覆盖保存决策、请求时机、输入不可变性、规范化与失败情形,不涉及真实的身份提供方。
