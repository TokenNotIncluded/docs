本词汇表定义项目本地化中使用的标准俄语术语。

## 核心概念

- 只有当源文本本身包含表情符号时才保留它们。
- 纯技术术语在源文本出现时可以保留。
- 在俄语技术用法中常见的英文术语(例如 API)可以保留英文。

| 英文术语 | 俄语术语 | 规范英文 | 说明 |
|--------------|--------------|-------------------|-------------|
| Ratio | Коэффициент | Ratio/Multiplier | 价格计算使用的倍率。**重要:**定价场景始终使用 **Коэффициент**,不要使用 **Множитель**。 |
| Token | Токен | Token | API 凭据,或模型处理的文本单位。 |
| Channel | Канал | Channel | API 供应方访问渠道。 |
| Group | Группа | Group | 用户或令牌的分类。 |
| Quota | Квота | Quota | 用户可用的服务额度。 |

## 模型相关

| 英文术语 | 俄语术语 | 规范英文 | 说明 |
|--------------|--------------|-------------------|-------------|
| Prompt | Prompt / Ввод | Prompt | 模型的输入内容。 |
| Completion | Вывод | Completion | 模型输出。**重要:**不要译为 “дополнение” 或 “завершение” 等替代词。 |
| Input | Ввод | Input/Prompt | 发送给模型的内容。 |
| Output | Вывод | Output/Completion | 模型返回的内容。 |
| Model Ratio | Коэффициент модели | Model Ratio | 不同模型的定价倍率。 |
| Completion Ratio | Коэффициент вывода | Completion Ratio | 输出定价的附加倍率。 |
| Price per call | Цена за запрос | Price per call | 每次 API 调用收取的价格。 |
| Pay-as-you-go | Оплата по объему | Pay-as-you-go | 按用量计费。 |
| Pay-per-view | Оплата за вызов | Pay-per-call | 每次调用的固定价格。 |

## 翻译指引

### Prompt 与 Input 的语境

- **Промпт**:用户交互、聊天与 LLM 语境。
- **Ввод**:技术处理、计费与计算语境。
- **规则**:对话界面使用 **Промпт**,后端与流水线描述使用 **Ввод**。

### Token 的语境

- API 令牌(API Token)
- 模型处理的文本 token(Text Token)
- 系统访问令牌(Access Token)

### 额度说明

- 用户服务额度。
- 有时译作 **Кредит**。

### 语言注意事项

- 本地化文件需要正确的复数形式(`_one`、`_few`、`_many`、`_other`)。
- 注意技术术语的格与变格。
- 注意语法性别(例如 `модель` 为阴性,`канал` 为阳性)。

### 统一术语

- **Completion / Вывод**:模型输出。
- **Ratio / Коэффициент**:价格倍率。
- **Redemption Code / Код обмена**:充值码的规范说法。
- **Provider / Поставщик**:对外提供 API 或模型的组织或服务。
