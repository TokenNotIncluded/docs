LMM API 是模型聚合网关。你在[控制台](https://api.lmm.best)注册并创建 API Key 之后，可以用同一套接口调用多家供应商的文本、图像、视频、音频、嵌入和审核模型。

控制台把 API Key 显示为「令牌」。

## 支持哪些协议

同一枚 API Key 可以按客户端原来的协议发送请求。

| 协议 | 入口 | 适用客户端 |
| --- | --- | --- |
| OpenAI | `/v1/chat/completions`、`/v1/responses` | OpenAI SDK、Codex、多数聊天应用 |
| Anthropic | `/v1/messages` | Claude Code、Anthropic SDK |
| Gemini | `/v1beta/models/{model}:generateContent` | Gemini 客户端 |

图像、音频、嵌入、重排序和审核也走 OpenAI 兼容入口。完整列表见[接入地址与端点](/docs/api-reference)。

## 什么时候使用

- 你要用一个账户调用多个模型供应商。
- 你要在现有客户端里更换地址和 API Key 后继续使用。
- 你要按实际用量付费。

## 理解核心概念

| 概念 | 含义 |
| --- | --- |
| **API Key** | 调用凭据，以 `sk-` 开头。你可以为它设置额度、有效期、模型范围和 IP 白名单。 |
| **额度** | 账户的计费单位。站点按 $1 = 500,000 额度换算，控制台以美元显示。 |
| **分组** | 决定这枚 API Key 可以调用哪些模型，以及使用哪一档计费倍率。 |
| **倍率** | 计费系数。扣费等于用量乘以模型倍率和分组倍率。见[模型与价格](/docs/models)。 |

可用模型、分组名称和倍率会调整。调用前以控制台的 **模型与价格** 页为准。
