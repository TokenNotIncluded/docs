## Common workflows

<Steps>
  <Step title="Authenticate requests">
    Use a panel access token or the relay API bearer contract described in [Authentication](/docs/authentication). Keep tokens server-side and rotate them when a session or deployment changes.
  </Step>
  <Step title="Choose a compatible endpoint">
    Start with the [relay API reference](/docs/api-reference), then select the protocol that matches your client: Chat Completions, Responses, Messages, Gemini, embeddings, media, or another supported format.
  </Step>
  <Step title="Validate in a safe environment">
    Run the checks in [Setup and startup](/docs/setup-startup) and the relevant deployment contract before changing production state.
  </Step>
  <Step title="Operate with evidence">
    Use the release, backup, PostgreSQL, Valkey, diagnostics, and incident pages to make changes reversible and auditable.
  </Step>
</Steps>
