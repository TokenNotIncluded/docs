## 1. 服务范围

我们提供账户管理、开发者控制台、模型 API、用量记录、开源赏金计划、交付证据、验收与结算等在线服务。

可用功能、地区、模型、额度、价格和第三方能力可能发生变化,以操作前展示的实时页面为准。

第三方模型、支付、代码托管和认证服务受其自身条款约束。

## 2. 账户与凭据

你必须提供真实、准确、完整的信息,并妥善保管密码、访问令牌和 API 密钥。账户下的一切活动由你负责。

不得将凭据出租、转让、共享或披露给未获授权的人。

如发现未授权访问、异常扣费或安全事件,请立即联系 support@lmm.best。请勿通过邮件发送密码或完整密钥。

## 3. 合法使用

服务仅限用于你有权处理的内容与输出。

你必须遵守适用法律、出口管制、制裁规则以及你所选模型供应方的使用政策。

被禁止的行为包括欺诈、侵权、分发恶意软件、绕过访问控制、攻击、使平台过载、未经授权的抓取,或未经授权将服务输出商业化,以及提交未获授权的个人或机密数据。

## 4. 计费、余额与赏金

模型用量、充值金额、货币、赏金奖励、平台费用、退款条件和结算时间,均以确认前展示的定价与订单信息为准。

充值不会自动续费。

请求按请求时展示的规则计费。

赏金资金按任务状态、验收、取消与争议规则结算。

除强制法律规定的情形、重复扣费、经核实的计费错误或未交付之外,已使用的数字余额通常不予退款。

## 6. 可用性与 AI 输出

服务依赖网络和第三方组件,可能进行维护、中断、变更或下线。

AI 输出可能不准确、不完整、过时,或与其他用户获得的结果相似,不构成法律、医疗、财务或专业建议。在将输出用于重要决策前请自行核实。

在法律允许的范围内,服务按“现状”和“现有可用”状态提供。

对于违法行为、欺诈、滥用、攻击、拒付欺诈或重大安全风险,我们可以在法律允许范围内限制接口、冻结相关余额、暂停或终止账户,并保留所需记录。

我们对与本服务相关的全部请求的累计责任,以引发该请求的事件发生前 12 个月内你已支付的总费用为上限,法律不允许限制的情形除外。

计费、退款、安全和隐私问题请联系 support@lmm.best。

我们会在合理期限内确认并处理。
