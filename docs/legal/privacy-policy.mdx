本政策说明 LIghtJUNction(“我们”)在你使用 LMM API、LMM Forge、网站、控制台和开源赏金服务时如何处理个人信息。

注册或使用我们的服务即表示你同意本政策。隐私请求或安全相关问题可联系 support@lmm.best。

## 1. 我们收集的信息

- **账户信息**:用户名、邮箱、哈希后的登录凭据、登录方式、账户状态和安全设置。
- **服务与计费信息**:运行所需的 API 密钥元数据、请求时间、模型与用量、余额、订单、充值交易、退款和赏金结算记录。
- **设备与安全信息**:IP 地址、浏览器与客户端标识、会话、错误日志、反滥用信号以及必要的审计日志。
- **你提交的内容**:赏金描述、提交证据、工单、反馈,以及你在 API 调用中提交的内容(含附件)。

我们只收集提供服务、保障安全、完成结算和履行法律义务所必需的信息,不要求与服务无关的敏感个人数据。

## 2. 处理目的与法律依据

我们处理信息用于创建和保护账户、认证请求、提供模型与赏金服务、计量与计费、处理退款、识别滥用、响应支持请求、提升可靠性,以及履行税务、反欺诈等法律义务。

需要你同意的处理,我们会在相应页面征求同意。你可以随时撤回同意,但若该处理为必要环节,部分功能可能随之停止。

## 3. 第三方处理与跨境传输

为完成你的请求,输入内容、必要的请求元数据和交付产物可能被发送给选定的模型供应方、支付处理方、代码托管服务、认证服务、邮件服务和基础设施服务。这些供应方按其自身条款与隐私政策处理信息。

跨境传输仅在提供服务、履行合同或法律允许的范围内发生。我们采取访问控制、传输加密和数据最小化措施。请勿提交你无权共享的个人、机密或受监管数据。

## 4. 数据保留

账户、用量、订单和安全审计日志通常在账户存续期间保留。账户注销后,我们只保留结算、争议、反欺诈和法律合规所需的记录,之后删除或匿名化。

请求数据的保留取决于其用途、排障需要以及相关第三方服务的保留设置。保留时长因记录类型、法律要求和安全必要性而异。

## 5. 安全措施

我们使用基于角色的访问控制、哈希凭据、密钥隔离、传输加密、审计日志和异常检测。

没有绝对安全的在线服务。如果我们发现可能影响你账户的安全事件,会在法律要求时通知你并采取补救措施。

## 6. 你的权利

在适用范围内,你可以请求访问、更正、删除、限制或导出个人数据,反对特定处理,并撤回同意。请使用与账户关联的邮箱联系 support@lmm.best,并清楚说明你的请求。我们可能要求你完成身份验证。

注销账户之前,请确保所有未结订单、退款和赏金义务已结算完毕。

## 7. Cookie、未成年人及政策更新

我们使用认证、安全和用户偏好所必需的 Cookie 或类似技术,不将其用于无关的用户画像。

我们的服务不面向低于法定年龄要求的人。若监护人发现未成年人未经授权披露信息,请立即联系我们。

本政策的更新版本会发布在本页面并标注新的生效日期。重大变更还会通过应用内通知或账户联系渠道告知。
