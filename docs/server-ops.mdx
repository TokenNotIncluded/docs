---
title: "服务器运维以人工操作为准"
sidebarTitle: "服务器运维"
description: "服务器运维以人工操作为准的流程与检查项。"
---

GitHub Actions 不再执行服务器诊断、修复或部署。服务器运维工作流、事件请求触发器和 SSH 传输都已移除,生产环境 SSH 凭据不再存放在 GitHub Actions 中。

服务器操作请使用由运维人员控制的 SSH 和原生部署 CLI。软件包管理的安装保留其签名软件包事务;独立的 systemd 安装使用单独的手动部署路径。

- [原生事务与验收](/docs/production-release-transaction)
- [手动 systemd 部署](/docs/manual-systemd-deployment)

服务器上的历史操作日志和恢复状态仍可人工检查。移除工作流自动化并不代表可以删除备份、事务锁或恢复证据。
