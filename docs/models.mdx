可用模型、分组和倍率以控制台 **模型与价格** 页为准。运营调整会立即显示在该页。

你也可以用 API Key 查询：

```bash
curl https://api.lmm.best/v1/models \
  -H "Authorization: Bearer sk-xxxxxxxx"
```

返回列表已按这枚 API Key 的分组和模型限制过滤。请求里的 `model` 使用返回结果中的 `id`。

## 选择分组

分组决定 API Key 可以调用哪些模型，以及按什么倍率计费。同一个模型可以出现在多个分组中，价格和稳定性不同。

创建 API Key 时选择分组，创建后也可以修改。API Key 只能调用所属分组中的模型。

| 分组类型 | 说明 |
| --- | --- |
| **默认 / 通用** | 覆盖主流模型。 |
| **低价分组** | 倍率更低。速度或稳定性可能较低，适合对时延不敏感的任务。 |
| **高速 / 高级分组** | 倍率更高。响应更快，适合 Claude Code、Codex 等交互场景。 |
| **免费 / 社区分组** | 由用户或社区提供。可用性和输出质量没有保证。 |

分组名称、可用模型和倍率会调整。以控制台 **模型与价格** 页为准。

## 计算文本费用

额度的内部单位是 quota。换算关系是 **$1 = 500,000 额度**。控制台显示美元金额。

```text
扣费额度 = (输入 tokens
          + 输出 tokens × 补全倍率
          + 缓存读取 tokens × 缓存倍率
          + 缓存写入 tokens × 缓存写入倍率)
        × 模型倍率
        × 分组倍率

金额(USD) = 扣费额度 ÷ 500,000
```

| 倍率 | 作用 |
| --- | --- |
| **模型倍率** | 区分模型价格。能力更强的模型倍率更高。 |
| **补全倍率** | 输出 token 相对输入 token 的价格系数，通常大于 1。 |
| **缓存倍率** | 命中提示词缓存时，缓存部分的价格系数，通常小于 1。 |
| **缓存写入倍率** | 写入缓存的价格系数。 |
| **分组倍率** | 同一模型在不同分组下的折扣或溢价，例如 `0.6x`。 |

## 查询当前单价

```bash
curl "https://api.lmm.best/v1/pricing?model=gpt-5.6-sol" \
  -H "Authorization: Bearer sk-xxxxxxxx"
```

| 字段 | 含义 |
| --- | --- |
| `model`、`group`、`currency` | 模型、分组和币种。币种为 `USD`。 |
| `billing_mode` | `per_token`、`per_request` 或 `tiered_expr`。 |
| `unit` | `million_tokens` 或 `request`。 |
| `input_price`、`output_price` | 每百万 token 的美元价格。适用于按 token 计费。 |
| `request_price` | 每次请求的美元价格。适用于按次计费。 |
| `group_ratio` | 当前分组倍率，包含你的分组折扣。 |

省略 `model` 时，接口返回这枚 API Key 已配置的全部模型。

<Warning>
  返回值是配置中的基础价。图像分辨率、音频时长、工具调用和缓存时长都会改变最终扣费。以实际用量为准。
</Warning>

## 查看按次和按张的价格

| 能力 | 计费方式 |
| --- | --- |
| 图像生成和编辑 | 按张。价格可以随分辨率和质量变化。 |
| 视频生成 | 按次或按秒，由模型决定。 |
| 音频转写和合成 | 按秒或按字符。 |
| 重排序 | 按 token 或按次。 |
| 内容审核 | 按次。 |

这些模型在 `/v1/pricing` 中返回 `billing_mode` 和对应的价格字段。

模型单价、分组倍率和可用分组会随上游成本与运营策略变化。控制台和 `/v1/pricing` 都读取当前配置。需要精确价格时，在请求前查询一次。

额度的充值和查询见[充值与计费](/docs/billing)。
