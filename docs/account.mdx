打开控制台的 **账户设置**，管理登录方式、两步验证、Passkey 和登录会话。

## 注册和登录

打开 [api.lmm.best](https://api.lmm.best)。

| 方式 | 说明 |
| --- | --- |
| **用户名和密码** | 注册时需要邮箱验证码。 |
| **Google** | 使用 Google 账号登录。 |
| **GitHub、Discord、LinuxDO、Telegram** | 登录已经绑定的账户。 |
| **Passkey** | 使用设备生物识别或安全密钥登录。 |

<Note>
  新账户使用用户名和密码，或使用 Google 注册。GitHub、Discord、LinuxDO 和 Telegram 用于登录已经绑定的账户。
</Note>

## 开启两步验证

在 **账户设置** 中开启两步验证。开启后，登录时还需要输入动态验证码。

<Steps>
  <Step title="保存备用码">
    开启时会生成一组备用码。把它们离线保存。
  </Step>
  <Step title="更换验证器">
    更换手机或验证器之前，先用备用码登录，然后重新绑定。
  </Step>
  <Step title="关闭两步验证">
    关闭时同样需要验证身份。
  </Step>
</Steps>

## 注册 Passkey

Passkey 使用设备的指纹、面容或硬件安全密钥登录。

- 在 **账户设置** 中注册。
- 注册和删除需要先完成一次安全验证。
- Passkey 绑定到当前账户。更换设备后需要重新注册。

## 管理登录会话

控制台列出当前账户的活跃会话，包括登录方式、IP、设备、最后活跃时间和过期时间。

| 操作 | 结果 |
| --- | --- |
| **查看会话列表** | 显示当前有效的登录设备。 |
| **吊销指定会话** | 该设备立即退出，包括当前设备。 |
| **吊销其他会话** | 保留当前设备，其他设备全部退出。 |
| **自动登出** | 默认开启。登录时间早于七天的会话会退出。 |

新账户默认开启「自动登出一周前的会话」。使用过程会更新最后活跃时间。会话是否过期按首次登录时间计算。

- 你可以在账户设置中关闭自动登出。关闭后，会话最长保留 30 天。
- 重置密码会吊销全部会话。
- 修改密码或其他安全设置后，旧会话立即失效。

<Warning>
  在公共电脑上结束使用后，手动退出登录。你也可以在自己的设备上执行 **吊销其他会话**。
</Warning>

## 遇到会话数量限制

为降低滥用风险，会话签发有数量限制。

- 每个账户的同时活跃会话数有上限。超过上限时，登录失败。先吊销旧会话，再重新登录。
- 短时间内创建过多会话时，账户会被临时限制。

正常使用不会触发这些限制。如果限制反复出现，修改密码并吊销全部会话。

## 注销账户

在 **账户设置** 中注销账户。注销会删除账户数据，余额和 API Key 同时失效，且无法恢复。

密钥的额度和权限见 [API Key](/docs/api-keys)。数据处理规则见[隐私政策](/docs/legal/privacy-policy)。
