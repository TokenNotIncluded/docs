本词汇表给出关键项目术语的参考译法,用于保持文档与本地化的一致性。

## 核心概念

| 英文术语 | 含义 | 说明 |
|--------------|---------|-------|
| Ratio | 价格计算中使用的倍率 | 所有定价逻辑与计费说明统一使用该词。 |
| Token | API 凭据或模型输入的文本单位 | 条件允许时优先使用更具体的称呼,例如 **API 令牌**、**文本 token** 或 **访问令牌**。 |
| Channel | API 供应方入口 | 用于供应方集成与流量路由。 |
| Group | 用户或令牌的分类 | 影响额度与定价策略。 |
| Quota | 可用服务额度 | 用户账户所拥有的数值化服务权益。 |

## 模型相关

| 英文术语 | 含义 | 说明 |
|--------------|---------|-------|
| Prompt | 模型的输入内容 | 在面向用户的界面中通常指提示词形式的文本。 |
| Completion | 模型输出 | 模型返回的结果。 |
| Input | 发送给模型的数据 | 包含提示词类内容与请求上下文载荷。 |
| Output | 模型返回的数据 | 包含补全结果与结构化输出载荷。 |
| Model Ratio | 每个模型的定价倍率 | 用于按模型族缩放用量成本。 |
| Completion Ratio | 应用于输出的价格倍率 | 与输入倍率分开的系数。 |
| Price per call | 单次请求费用 | 固定计费模式。 |
| Pay-as-you-go | 按用量计费 | 按消耗单位计费。 |
| Pay-per-view | 按调用计费 | 旧界面文案中使用过的另一种说法。 |

## 用户管理

| 英文术语 | 含义 | 说明 |
|--------------|---------|-------|
| Root User | 最高权限账户 | 通常是运维级管理员角色。 |
| Admin User | 系统管理员 | 可以管理用户、策略和平台设置。 |
| Normal User | 普通账户 | 无额外权限。 |

## 充值与兑换

| 英文术语 | 含义 | 说明 |
|--------------|---------|-------|
| Top Up | 为账户增加额度 | 增加可用余额或点数。 |
| Redemption Code | 可兑换额度的码 | 也用于类似优惠券的促销场景。 |

## 渠道管理

| 英文术语 | 含义 | 说明 |
|--------------|---------|-------|
| Channel | 供应方集成渠道 | 决定 API 请求的路由去向。 |
| Key | API 访问密钥 | 用于认证时,界面文案优先使用 **API 密钥**。 |
| Priority | 渠道选择优先级 | 数值越高越优先路由。 |
| Weight | 负载均衡权重 | 用于在多个渠道之间分流。 |
| Proxy | 代理服务器地址 | 可能包含协议与主机校验规则。 |
| Model Mapping | 请求模型重映射 | 改写请求体中的模型名称。 |

## 安全相关

| 英文术语 | 含义 | 说明 |
|--------------|---------|-------|
| Two-Factor Authentication | 额外的账户验证步骤 | 通常简写为 2FA。 |
| 2FA | 双重验证 | 统一使用大写缩写。 |

## 计费相关

| 英文术语 | 含义 | 说明 |
|--------------|---------|-------|
| Ratio | 价格倍率 | 在许多语境下与 Multiplier 同义。 |
| Multiplier | 价格倍率 | 与 ratio 语境同时出现时注意避免重复表述。 |

## 翻译说明

- **Prompt**:模型输入。
- **Completion**:模型输出。
- **Ratio**:用于价格计算的倍率。
- **Quota**:可用服务额度;有时也译作**点数**。
- **Token** 在不同语境下可能指:
  - API 令牌
  - 文本 token
  - 访问令牌
