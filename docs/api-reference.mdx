LMM API 提供两套机器可读的 OpenAPI 契约。接入模型或媒体请求时使用中继契约，管理面板、账户、模型、计费和运维时使用管理契约。

## 基础地址

两个契约共用同一个生产基础地址,端点路径直接拼接在其后。

```text
https://api.lmm.best
```

例如模型列表端点的完整地址为 `https://api.lmm.best/v1/models`,面板登录端点为 `https://api.lmm.best/api/user/login`。

## 认证

中继端点和多数管理端点使用 Bearer 令牌:

```bash
curl https://api.lmm.best/v1/models \
  -H "Authorization: Bearer $LMM_API_KEY"
```

登录、刷新和登出使用 HttpOnly 刷新 Cookie,高风险操作额外要求 `X-Security-Proof` 请求头。令牌、Cookie、PAT 和会话限制的完整说明见[认证与会话](/docs/authentication)。

<Info>
  侧边栏 **API 端点** 分组中的每个页面都由 OpenAPI 规范自动生成,包含参数表、响应结构、错误码、代码示例和可交互的请求构造器。规范更新后端点页面自动跟随,不需要手写。
</Info>

<AccordionGroup>
  <Accordion title="中继 API:模型与媒体">
