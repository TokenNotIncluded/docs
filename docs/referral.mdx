好友通过你的邀请完成首次充值后，奖励额度记入你的账户。打开控制台的 **邀请 / 推广**。

## 获取邀请码和链接

页面上方显示邀请码和专属邀请链接。好友通过链接注册后，系统绑定邀请关系。注册时也可以手动填写邀请码。

<Steps>
  <Step title="复制邀请信息">
    打开 **邀请 / 推广**，复制邀请链接或邀请码。
  </Step>
  <Step title="发送给好友">
    好友通过该链接注册。邀请关系自动绑定。
  </Step>
  <Step title="等待首次充值">
    好友完成首次充值后，奖励自动记入你的账户。
  </Step>
</Steps>

## 了解发放规则

| 项目 | 说明 |
| --- | --- |
| **发放条件** | 被邀请人首次通过正规支付渠道完成充值。 |
| **奖励对象** | 发出邀请的账户。 |
| **奖励形式** | 平台额度，直接记入账户。 |
| **发放时机** | 支付结算完成后入账，通常在几分钟内。 |
| **人数** | 没有固定上限。异常批量邀请会触发风控。 |

奖励金额、首充门槛和封顶规则以邀请页当时的显示为准。

<Info>
  每个被邀请人只计算一次，每笔充值只发放一次。手动开通、赠送、管理员调整、钱包转账和订阅不计入。
</Info>

## 确认哪些充值计入

只有通过正规支付渠道完成的现金充值会触发奖励。以下方式不计入：

- 管理员手动完成的订单
- 钱包转账和账户间转账
- 活动赠送和签到奖励
- 兑换码和红包
- 订阅类订单

## 了解撤销和罚扣

以下行为会撤销已发放的奖励，并对邀请人追加额度罚扣：

- 被邀请账户因滥用或批量注册被封禁
- 同一人使用多个账户互相邀请
- 使用临时邮箱或随机用户名批量注册

<Warning>
  只签到而不使用服务，或用户名明显是随机字符串的账户，会被封禁。如果账户被误封，在控制台提交工单并说明情况。
</Warning>

## 处理退款

被邀请人的充值被全额退款时，对应的邀请奖励会被撤销。部分退款不影响奖励，直到原始支付金额被全部退回。

## 查看邀请记录

邀请页显示：

- 邀请链接和邀请码
- 已邀请人数
- 累计奖励额度
- 奖励明细，包括发放、收回、罚扣和申诉冲正
