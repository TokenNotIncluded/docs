## Documentation areas

- **Core operation:** authentication, upgrades, release architecture, pricing, memory, PostgreSQL, Valkey, Rust rollout, and testing.
- **API contracts:** admin and relay OpenAPI definitions, read-only queries, response compatibility, image polling, and remote control.
- **Product and governance:** payments, referrals, bounties, tool market behavior, terminology, and assistant workflows.
- **Security and incidents:** audits, recovery procedures, incident records, and registration safeguards.
- **Legal:** user agreement, privacy policy, and terms of service.
