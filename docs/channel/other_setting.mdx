本文定义可选的渠道参数。它以 JSON 对象配置,当前包含以下选项。

1. force_format
   - 表示是否强制把输出转换为一套兼容 OpenAI 的格式。
   - 布尔值。
   - 设为 `true` 启用强制格式化。

2. proxy
   - 配置网络代理。
   - 字符串值,支持 `http`、`https`、`socks5` 和 `socks5h` 协议。
   - 保存的值必须包含协议与主机,只允许空路径或 `/`。
   - 不允许查询串与片段。
   - SOCKS 未提供端口时,运行时默认使用 `1080` 端口。

3. thinking_to_content
   - 把 `reasoning_content` 转换为 `<think>` 包裹的片段并追加到返回内容中。
   - 布尔值。
   - 设为 `true` 启用该行为。

---

## JSON 示例

下面是启用强制格式化并设置代理地址的示例配置:

```json
{
    "force_format": true,
    "thinking_to_content": true,
    "proxy": "socks5://proxy.example:1080"
}
```

---

调整这些 JSON 取值即可控制渠道行为,包括是否强制格式化以及使用哪个网络代理。

## 升级兼容性

旧版本会忽略代理 URL 中的路径、查询串和片段。为避免升级后中断既有流量,运行时会继续剥离这些后缀,并且对每个进程中出现的、不含凭据也不含后缀的代理地址只记录一次告警。该兼容层不会改写任何数据库记录。

保存更新后的渠道配置时,请把代理地址改为上文的严格格式。

代理连接使用 30 秒 TCP 拨号超时、30 秒 keep-alive 超时和 10 秒 TLS 握手超时。未配置渠道代理时,这些超时同样作用于中继请求。
